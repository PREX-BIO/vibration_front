# 01. 아이폰 측정 절차와 결과 화면

## 1. 사용 흐름

사용자가 시작 버튼을 누르고 책상 위 휴대폰의 양옆 중앙을 엄지와 검지로 집으면, 앱이 동작을 안내합니다. 센서 특징을 임시 모델에 넣어 **집게힘 데모값**을 표시합니다.

| 항목 | 자세 |
|---|---|
| 휴대폰 | 단단하고 수평인 책상에 뒷면을 대고 놓고 화면은 위로 향하게 합니다. |
| 방향 | 휴대폰 상단을 사용자에게서 먼 쪽으로 둡니다. |
| 엄지·검지 | 오른손 엄지는 오른쪽 긴 변 중앙, 검지는 왼쪽 긴 변 중앙에 둡니다. |
| 힘 | 지복으로 양옆을 마주 보는 방향으로 집습니다. |
| 지지 | 전완을 책상에 편하게 둡니다. 나머지 손가락·손바닥은 휴대폰에서 떨어뜨립니다. |
| 완화 | 손가락 위치를 유지하며 힘을 낮춥니다. |

같은 책상 위치와 케이스 상태로 반복합니다. 세 번 모두 편안한 범위에서 집으며 최대 힘을 요구하지 않습니다. 따라서 결과 이름도 `최대 집게힘`으로 붙이지 않습니다.

## 2. 기존 시간표 유지

3초 준비가 끝나면 `t=0`부터 35초 기록합니다. 구간은 시작 포함·끝 제외입니다.

| 시간(초) | phase_id | 안내 | 진동 패턴 |
|---:|---|---|---|
| 0–3 | `off_start` | 가볍게 접촉 | 꺼짐 |
| 3–5 | `motor_settle` | 위치 유지 | 펄스 시작 |
| 5–9 | `baseline` | 가볍게 접촉 | 유지 |
| 9–13 | `pinch_1` | 집어서 유지 | 유지 |
| 13–17 | `light_1` | 접촉을 유지하며 힘 낮추기 | 유지 |
| 17–21 | `pinch_2` | 집어서 유지 | 유지 |
| 21–25 | `light_2` | 접촉을 유지하며 힘 낮추기 | 유지 |
| 25–29 | `pinch_3` | 집어서 유지 | 유지 |
| 29–33 | `light_3` | 접촉을 유지하며 힘 낮추기 | 유지 |
| 33–35 | `off_end` | 가볍게 접촉 | 종료 |

이는 기존 iOS 펄스 패턴의 실행 구간입니다. 30초 동안 모터가 끊김 없이 진동한다는 의미가 아닙니다. 현재 앱의 패턴을 유지하고, kgf 출력 추가와 진동 방식 변경을 동시에 진행하지 않습니다.

## 3. 화면 구성

| 화면 | 주 내용 |
|---|---|
| 준비 | 접점 도식, 책상·케이스 조건, 진동 시험, 시작 버튼 |
| 측정 | 현재 동작, 남은 시간, **집게힘 · 데모값 … kgf**, 시간 그래프 |
| 결과 | **대표 데모값 … kgf**, 1·2·3회 결과, 다시 측정·JSON 공유 |
| 상세 | 원본 RMS, 비율, 관측 속도, 품질 메모, 모델 ID·계수 |

처음 9초에는 `기준을 잡고 있습니다`를 표시합니다. 기준이 만들어진 뒤 유효한 특징이 들어오면 kgf를 표시합니다. 꺼짐·전이·무효 구간은 `—`로 두고 그래프를 끊습니다.

결과 숫자는 소수점 첫째 자리까지 표시합니다. 내부 계산과 저장에서는 반올림하지 않습니다. `데모값` 표시는 숫자와 함께 항상 보이게 합니다. 설명을 반복 팝업으로 띄우지는 않습니다.

## 4. 대표값

각 집기 구간의 첫 1초를 제외하고 센서 비율의 중앙값을 구한 뒤, 그 값을 임시 모델에 넣습니다. 세 번 모두 유효하면 세 kgf 결과의 중앙값을 최종 카드에 표시합니다.

예: `3.8 / 8.2 / 4.1 kgf` → 대표 데모값 `4.1 kgf`.

입력 창이 부족한 반복은 비워 둡니다. 세 결과가 모두 확보되지 않으면 유효한 개별 결과를 보여주고 대표값은 `—`로 표시합니다.

## 5. 측정 후 확인

휴대폰이 밀리거나 들렸는지, 다른 손가락·손바닥이 닿았는지 선택할 수 있게 합니다. 처음 값은 `null`이며 사용자의 확인 후 갱신합니다. 관찰 내용은 저장하되 임의의 보정 계수로 사용하지 않습니다.
