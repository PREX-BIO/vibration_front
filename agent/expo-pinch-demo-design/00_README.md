# 아이폰 Expo 집게힘 데모 — 구현 문서 v2

**버전:** 2.0 · **수정일:** 2026-11-18  
**대상:** 현재 실행 중인 iPhone · Expo Go · React Native 앱

## 이번에 완성할 결과

휴대폰을 집어서 측정하면 **집게힘 숫자가 kgf로 표시되는 데모**를 만듭니다. 현재 앱이 수집하는 실제 센서값에 임시 회귀 계수를 적용해 결과를 계산합니다.

화면의 주 결과는 `집게힘 · 데모값 4.1 kgf`입니다. 관측 속도·RMS·변동계수는 결과 상세로 이동합니다. 임시 계수로 만든 출력임은 결과 옆의 `데모값` 표시와 저장 메타데이터로 유지합니다.

## 처리 흐름

| 단계 | 이번 구현 |
|---|---|
| 측정 | 현재 아이폰 앱의 펄스 진동·가속도 수집 유지 |
| 특징 계산 | 500 ms RMS → 최초 가벼운 접촉 기준으로 나눈 비율 `r` |
| 힘 계산 | `F_demo = clamp(1 + 5 × (r − 1), 0, 15)` kgf |
| 구간 요약 | 세 집기 구간 각각의 대표값 계산 |
| 최종 표시 | 세 집기 데모값의 중앙값 |
| 저장 | 원본 + 특징 + 임시 모델 설정 + kgf 출력 |

1, 5, 15는 **시연용으로 정한 값**입니다. 논문에서 가져온 학습 계수나 사람의 정상 범위가 아닙니다. 계산 과정을 구현하고 나중에 학습 모델을 연결할 수 있도록 정한 초기 설정입니다.

## v2의 구현 기준

- 실행 환경은 **사용자가 이미 측정에 사용한 iPhone Expo Go**입니다.
- `expo_desk_pinch_ios_pulsed_v1` 프로토콜과 35초 진행을 유지합니다.
- 이번 작업의 필수 범위는 임시 모델·kgf 화면·결과 저장입니다.
- 임시 계수 지정은 이번 사용자가 요청한 데모 범위입니다.
- 기준 힘 센서 확보나 모델 학습을 이번 데모의 선행조건으로 두지 않습니다.
- 원본 신호가 없는 구간에는 숫자를 만들어 채우지 않습니다.

v1의 Android 우선·kgf 출력 보류 지시는 이 문서 묶음으로 대체합니다. 기존 Google Docs는 이번 작업에서 수정하지 않았습니다.
