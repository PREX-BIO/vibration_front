# 06. 코딩 에이전트에게 전달할 보완 지시

아래 지시문과 이 폴더 전체를 함께 전달합니다.

---

현재 iPhone Expo Go에서 실행 중인 React Native 앱에 **집게힘 숫자를 kgf로 출력하는 데모**를 추가해 주세요.

목표는 실제 센서값을 임시 모델에 넣고, 측정 완료 시 `집게힘 · 데모값 4.1 kgf`처럼 결과를 보여주는 것입니다. 사용자는 데모를 위해 임의 계수 사용을 요청했습니다.

먼저 `07_FORCE_ESTIMATION_DEMO.md`를 읽고, `03_SIGNAL_AND_DATA.md`의 데이터 계약과 `04_ACCEPTANCE.md`의 계산 예시를 확인하세요.

## 유지할 것

- iPhone·Expo Go·현재 Expo SDK.
- `expo_desk_pinch_ios_pulsed_v1`과 기존 펄스 진동.
- 35초 진행, 가속도 수집, RMS·기준 비율 계산.
- 책상 위 엄지–검지 자세와 JSON 공유.

## 추가할 것

1. 임시 모델 설정을 독립 파일로 분리합니다.
2. 입력은 기존 `accel_rms_ratio`이며, 반복 요약에서는 `pinch_ratio`를 사용합니다.
3. 임시 기본값은 `mean=[1]`, `scale=[1]`, `coefficients=[5]`, `intercept=1`, 출력 단위 `kgf`입니다.
4. 계산식은 `F_raw=1+5×(r−1)`, 표시 범위는 `0–15 kgf`입니다.
5. `predictForce(features, model)`를 순수 TypeScript 함수로 작성합니다.
6. 실시간 카드·그래프와 세 구간 결과를 연결합니다.
7. 세 번의 kgf 결과 중앙값을 대표값으로 표시합니다.
8. 모델 스냅샷, 원시·범위 처리 후 값, `kind=demo`를 저장합니다.
9. 결과 옆에 `데모값`을 항상 표시하고 기술적 설명은 상세로 배치합니다.
10. 센서 비율 자체가 없는 구간은 `null`로 유지합니다.

## 공유된 JSON으로 검증

`pinch_20261118T035925274Z_le1zl-0dn72y.json`의 세 `pinch_ratio`를 모델에 넣으면 다음 값이 나와야 합니다.

| 반복 | 데모 표시 |
|---|---:|
| 1 | 3.8 kgf |
| 2 | 8.2 kgf |
| 3 | 4.1 kgf |
| 대표 중앙값 | 4.1 kgf |

`median_trial_delta`는 모델 입력이 아닙니다. 모델 입력과 결과를 매 세션에 저장해 재계산 가능하게 해 주세요.

## 범위 판단

이번 요청에서 임시 계수는 허용된 구현 조건입니다. 기준 힘 센서가 없다는 이유로 kgf 데모 출력을 보류하지 마세요. 논문은 ‘특징→회귀 모델→힘’ 구조의 참고 자료이며, 위 계수는 우리 데모에서 정한 값입니다. 이를 논문 학습 계수라고 표시하지 마세요.

`weak_motor_response`·`unstable_baseline` 같은 관찰 메모는 상세에 보존하되, 입력이 계산 가능한 경우 데모 출력을 막지 마세요. 무효 입력·기준 부재·세션 중단은 기존 품질 규칙에 따라 처리하세요.

새로운 네이티브 진동 모듈이나 서버를 이번 작업의 필수 범위로 추가하지 마세요. 현재 앱의 수집부 뒤에 모델과 UI를 연결하는 변경부터 완성하세요.
