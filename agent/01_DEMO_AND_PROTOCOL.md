# 01. 사용 흐름과 측정 절차

## 1. 사용자가 하게 될 일

사용자가 시작 버튼을 누르고 손가락을 접점에 놓으면 앱이 동작을 안내합니다. 진동을 주는 동안 집기와 가벼운 접촉을 세 차례 반복합니다. 결과에서는 신호의 변화와 각 구간을 함께 보여줍니다.

첫 자세는 **오른손 엄지–검지 집기**입니다. 나머지 네 자세는 첫 데모를 확인한 뒤 같은 화면과 데이터 구조에 추가합니다.

## 2. 책상 위 자세

| 항목 | 방법 |
|---|---|
| 휴대폰 | 단단하고 수평인 책상 위에 뒷면을 대고 놓습니다. 화면은 위를 향하고 휴대폰 상단은 사용자에게서 먼 쪽에 둡니다. |
| 엄지 | 화면을 위에서 보았을 때 오른쪽 긴 변의 중앙을 지복으로 누릅니다. |
| 검지 | 왼쪽 긴 변의 중앙, 엄지와 같은 높이에 둡니다. |
| 집는 방향 | 양옆을 서로 마주 보는 방향으로 집습니다. |
| 나머지 손가락 | 편하게 굽히고 휴대폰에서 떨어뜨립니다. |
| 지지 | 전완을 책상에 편하게 둡니다. 손바닥으로 휴대폰을 받치거나 누르지 않습니다. |
| 힘을 낮출 때 | 손가락을 떼지 않고 같은 위치에서 힘을 낮춥니다. |

세 번 모두 편안한 범위에서 비슷한 느낌의 힘을 사용합니다. 최대 힘을 요구하지 않습니다. 불편하면 중단합니다.

같은 책상 위치와 케이스 상태로 반복합니다. 기기가 밀리거나 카메라 돌출부 때문에 흔들리면 결과에서 그 사실을 표시합니다. 임의의 수건·스펀지·고무판은 첫 기본 조건에 추가하지 않습니다.

## 3. 시간표

시작 후 3초는 준비 시간입니다. 준비가 끝난 시점을 `t=0`으로 두고 35초간 기록합니다. 아래 구간은 시작 포함, 끝 제외입니다.

| 시간(초) | phase_id | 안내 | 진동 |
|---:|---|---|---|
| 0–3 | `off_start` | 가볍게 접촉 | 꺼짐 |
| 3–5 | `motor_settle` | 손가락 위치 유지 | 켜짐 |
| 5–9 | `baseline` | 가볍게 접촉 | 유지 |
| 9–13 | `pinch_1` | 조금 더 세게 집고 유지 | 유지 |
| 13–17 | `light_1` | 접촉을 유지하며 힘 낮추기 | 유지 |
| 17–21 | `pinch_2` | 조금 더 세게 집고 유지 | 유지 |
| 21–25 | `light_2` | 접촉을 유지하며 힘 낮추기 | 유지 |
| 25–29 | `pinch_3` | 조금 더 세게 집고 유지 | 유지 |
| 29–33 | `light_3` | 접촉을 유지하며 힘 낮추기 | 유지 |
| 33–35 | `off_end` | 가볍게 접촉 | 꺼짐 |

진동은 3–33초의 30초 동안 같은 명령을 유지합니다. 안내는 글자와 진행 막대로 제공하고, 추가 효과음·햅틱은 넣지 않습니다. 측정 중 사용자가 화면을 누를 필요는 없습니다.

## 4. 화면 3개

### 준비 화면

제목: **집기 반응 데모**

| 요소 | 내용 |
|---|---|
| 설명 | “휴대폰을 책상에 놓고 엄지와 검지로 양옆 중앙을 집어 주세요.” |
| 도식 | 휴대폰 평면도, 좌우 중앙 접점, 책상 지지 표시 |
| 조건 | 책상 종류 선택, 케이스 있음/없음 |
| 기기 점검 | 가속도계 이용 가능 여부, 진동 시험 버튼 |
| 시작 | `측정 시작` |

도식은 `react-native-svg` 또는 단순 View로 그립니다. 손가락 전체 모양을 만들지 않고 **접점 두 개와 힘의 방향**을 분명히 표시합니다.

진동 시험은 Android에서 짧게 한 번 실행하고 사용자가 느껴지는지 확인합니다. 진동 API 호출 성공만으로 실제 진동이 발생했다고 확정하지 않습니다. 시험이 끝나고 자세를 잡은 뒤 측정을 시작합니다.

### 측정 화면

| 위치 | 내용 |
|---|---|
| 상단 | 현재 동작을 큰 글씨로 표시 |
| 그 아래 | 전체 진행과 현재 단계 남은 시간 |
| 중앙 | `기준 대비 센서 변동 0.82배` |
| 그래프 | 시간에 따른 비율, 1.00 기준선, 집기 구간 음영 |
| 하단 | `중단` 버튼 |

처음 9초에는 `기준 신호를 수집하고 있습니다`를 표시합니다. 기준값이 준비되면 비율 그래프를 보여줍니다. 기준값을 만들지 못하면 실제 가속도 변동값과 `기준 비교를 만들지 못했습니다`를 표시합니다.

색상은 진행과 구간을 구분하는 데 사용합니다. 강함·약함·건강 상태를 판정하는 게이지는 넣지 않습니다.

### 결과 화면

| 요소 | 내용 |
|---|---|
| 결과 상태 | 기록 완료 또는 중단 |
| 그래프 | 전체 기록과 세 번의 집기 구간 |
| 비교표 | 각 집기 비율, 직전 가벼운 접촉 비율, 차이 |
| 간단 확인 | “휴대폰이 밀리거나 들렸나요?” 예/아니요 |
| 실행 | `다시 측정` / `JSON 공유` |

기술적인 수집 속도·누락·진동 반응 상태는 `측정 상세` 안에 둡니다. 결과값이 없을 때에는 `—`를 표시하고 이유를 상세에서 설명합니다.

## 5. 표시 언어

| 사용 | 예 |
|---|---|
| 센서값 설명 | “기준 대비 센서 변동 0.82배” |
| 구간 비교 | “첫 집기 구간에서 기준보다 0.18 낮게 기록되었습니다.” |
| 원본 출처 | “실측” 또는 “예시 재생” |
| 분석 어려움 | “센서 수집이 고르지 않아 일부 구간을 비웠습니다.” |

집기 안내가 나간 시간은 사용자가 따라 할 **동작 라벨**입니다. 실제 힘의 정답값으로 저장하거나 사용하지 않습니다.
